# Project Euler

My solutions to [Project Euler](https://projecteuler.net/) problems, implemented in multiple programming languages.

The purpose of this repository is to develop mathematical problem-solving, algorithmic thinking, programming ability with different programming languages.

Rather than focusing solely on obtaining the correct answer, I aim to understand the mathematics behind each problem, develop efficient algorithms, and reflect on the approaches I use.

## Languages

* C#
* Python

## Approach

For each problem, I aim to:

1. Understand the mathematical problem.
2. Attempt a solution independently.
3. Identify an appropriate algorithm.
4. Consider the efficiency and complexity of the approach.
5. Implement the solution.
6. Test the implementation where appropriate.
7. Reflect on what I learned and what could be improved.

For more difficult problems, I may document multiple approaches and compare their trade-offs.
